ERROR 1 — N split wrong (text says 96/54, data has 97/53)
Location: Section 4 (sample description), Section 5.3, and Table 3 note.
Old value: "N=150 processes (N=96 ending at partial, N=54 reaching comprehensive)"
New value: "N=150 processes (N=97 ending at partial, N=53 reaching comprehensive)"
Old value (Section 5.3): "N=54 processes"
New value (Section 5.3): "N=53 processes"
Explanation: The dataset variable FPS_Binary has 97 cases coded 0 (process did
not reach comprehensive settlement) and 53 cases coded 1 (process reached
comprehensive settlement). The manuscript erroneously states 96 and 54. This is
a one-case off-by-one error that must be corrected in every location it appears,
including any table notes referencing the split.
Note: All percentage calculations derived from this split must also be recomputed.
Success rate: 53/150 = 35.3% (not 54/150 = 36.0%). This 0.7 percentage-point
difference should be updated in the text wherever the success rate is stated.

ERROR 2 — Is_Local coefficient is mathematically impossible
Location: Section 5.5 (or equivalent section reporting Model 7), Table 1 Model 7.
Old value: "Is_Local (B = 0.077, SE = 0.505, p > .05)"
New value: Is_Local should be removed from Model 7 entirely.
Replacement text: "Is_Local was excluded from Model 7 due to zero variance in the
analytical sample (all 150 processes were coded as national or regional; n=2
missing values). A zero-variance predictor produces a singular design matrix and
cannot yield a valid coefficient estimate."
Explanation: The variable Is_Local equals 0 for all 150 processes in the dataset
(with 2 missing values). A predictor with zero variance contributes no information
to a regression model and causes the design matrix to be singular. The software
cannot estimate a coefficient; any reported value (B=0.077, SE=0.505) would be
an artifact of numerical instability or a coding error in the analysis script.
The author's own text acknowledges "no variance in the sample as all processes
are national or regional" — reporting a coefficient for this variable is internally
contradictory. Is_Local must be dropped from Model 7.
Additional note: Removing Is_Local does not affect TjMech_c (B=0.487 confirmed
correct without Is_Local), but it does affect AgtNrs (see ERROR 3).

ERROR 3 — AgtNrs coefficient wrong (sign reversed)
Location: Section 5.5 (or equivalent), Table 1 Model 7.
Old value: "AgtNrs (B = 0.004, SE = 0.012)"
New value: "AgtNrs (B = −0.021, SE = 0.015, p = .163)"
Explanation: Replication of Model 7 with Is_Local correctly excluded (see ERROR 2)
yields AgtNrs B = −0.021, SE = 0.015, p = 0.163. The manuscript's reported value
of B = 0.004 has both the wrong sign and wrong magnitude. The discrepancy is
likely caused by two compounding errors: (a) Is_Local was incorrectly retained
in the model despite zero variance, causing numerical instability that distorted
AgtNrs's estimated coefficient; and (b) a possible transcription or copy-paste
error. The corrected value (B = −0.021) remains non-significant (p = .163), so
the substantive conclusion (AgtNrs does not significantly predict final peace
settlement) is unchanged, but the direction of the effect is reversed: more prior
agreements is associated with slightly lower (not higher) probability of reaching
comprehensive settlement, though this effect is not statistically reliable.

ERROR 4 — Random Forest variable importance values wrong (rank order and magnitudes)
Location: Section 6.1, and any table/figure reporting RF importance scores.
Old values: "TjPrire 0.1335, TjVic 0.1318, TjNR 0.1306, TjMech 0.1270"

New values: "TjMech 0.1378, TjPrire 0.1310, TjVic 0.1297, TjNR 0.1233"

Explanation: 100-iteration replication of the Random Forest model produces
importance scores that differ from those reported in the manuscript. The key

substantive finding — that all four core theorized TJ provisions (TjMech, TjPrire,

However, the manuscript's theoretical argument specifically emphasizes TjMech
(truth mechanisms) as the primary predictor, and the corrected RF importance
values now align with this argument; the old values created an inconsistency
between the RF results and the logistic regression results. The correction
strengthens, not weakens, the paper's main claim.
Note: The complete ranking of all 9 TJ variables and any additional predictors
in the RF model should be reported in a table; if a figure displays importance
scores, it must be regenerated with the corrected values.
